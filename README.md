# phuture-previews — Vercel setup

A tiny Vercel proxy that serves mockup HTML from Supabase Storage at
`previews.phuturedigital.co.za/{slug}`.

## How it works

1. Browser hits `previews.phuturedigital.co.za/faded-blades-barbershop-f8c0e1`
2. Vercel rewrites `/[slug]` → `/api/mockup?slug=[slug]`
3. The Edge Function at `/api/mockup` fetches the HTML from Supabase Storage
   and returns it with the right headers
4. Browser renders the mockup

Vercel Edge Functions correctly serve `Content-Type: text/html` to the
browser, unlike Supabase Edge Functions (which strip/modify headers in
ways that break HTML rendering).

## Files

- `api/mockup.ts` — the Edge Function that proxies Storage
- `vercel.json` — rewrite rules (any path → mockup function)
- `public/index.html` — fallback page if someone visits the bare domain

## Deploy steps (one-time)

### 1. Push to GitHub

Create a new GitHub repo (e.g. `phuture-previews`) and push these files:

```sh
cd phuture-previews
git init
git add .
git commit -m "Initial Vercel proxy for mockup previews"
git branch -M main
git remote add origin git@github.com:<your-username>/phuture-previews.git
git push -u origin main
```

### 2. Import to Vercel

1. Go to https://vercel.com/new
2. Import the `phuture-previews` repo
3. Framework preset: **Other** (no framework, plain Vercel project)
4. Root directory: leave as `.`
5. Build command: leave empty
6. Output directory: leave empty
7. Click Deploy

You'll get a default URL like `phuture-previews.vercel.app`.

### 3. Test before adding the custom domain

Visit `https://phuture-previews.vercel.app/faded-blades-barbershop-f8c0e1`.

You should see the fully rendered Faded Blades mockup. If you see plain
code, something's wrong with the deploy — check the Vercel build logs.

### 4. Add the custom domain

In the Vercel project dashboard:
1. Settings → Domains → Add `previews.phuturedigital.co.za`
2. Vercel will tell you to add a CNAME DNS record:
   - Type: `CNAME`
   - Name: `previews`
   - Value: `cname.vercel-dns.com`
3. Add that record at your domain DNS provider for `phuturedigital.co.za`
4. Wait 1–10 minutes for DNS to propagate, then Vercel will auto-issue an SSL cert

### 5. Verify

Visit `https://previews.phuturedigital.co.za/faded-blades-barbershop-f8c0e1`.

You should see the rendered mockup. If yes, the pipeline is live.

## How to deploy updates

Push to the GitHub `main` branch. Vercel auto-deploys.

This project changes rarely — the mockup HTML lives in Supabase Storage
and is regenerated by the Supabase Edge Function. This Vercel project is
only the proxy.
